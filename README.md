# dotfiles

Personal configs, so my terminal looks the way I want.

```
 󰣇 rey  ~   master !  󰅐 05:43 
❯
```

- `starship.toml` → `~/.config/starship.toml`
- `ghostty/config` → `~/.config/ghostty/config`
- `tmux/tmux.conf` → `~/.config/tmux/tmux.conf`

Run `./install.sh` to symlink them into place. The installer also fetches the
Catppuccin tmux theme when needed. Needs `tmux`, `starship`, `git`, and a Nerd
Font.
